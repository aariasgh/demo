## Executive Summary

**Objetivo**: Validar todas las funcionalidades de accesibilidad implementadas en E6-S3 mediante pruebas automatizadas end-to-end con Playwright y auditorías de accesibilidad WCAG AA.

**Valor de Negocio**: 
- Garantizar cumplimiento WCAG AA en todos los flujos de usuario
- Prevenir regresiones de accesibilidad en futuras versiones
- Validar usabilidad de teclado (11 shortcuts) y lectores de pantalla

**Dependencias**: 
- Depende de E6-S1 a E6-S5 (todas las features de accesibilidad implementadas)
- No bloquea otros epics
- Puede ejecutarse en paralelo con E7/E8

- [ ] **AC-2.1**: ARIA labels y descriptions validados

  - `aria-describedby` referencia descripciones útiles

  - `role="dialog"` en CreateLeadModal, QuickNotesModal, QuickStatusModal

## Strategy de Pruebas

### Phase 1: Automated Tests (Playwright + axe-core)
1. Install `@axe-core/playwright`
2. Create test file: `frontend/e2e/accessibility.spec.ts`
3. Test coverage:
   - Initial page load + axe scan
   - KanbanBoard loaded + axe scan
   - CreateLeadModal opened + axe scan
   - QuickNotesModal opened + axe scan
   - QuickStatusModal opened + axe scan
   - RiskWidget toggled + axe scan
   - SearchFilterHeader focused + axe scan
4. Assert: 0 violations (critical/serious), log warnings
5. Run: `pnpm exec playwright test --grep "accessibility"`

### Phase 2: Keyboard Navigation (Manual + Recorded)
1. Create test cases for each of 11 shortcuts
2. Test focus trap in modals (Tab circular, Escape closes)
3. Test arrow navigation in Kanban (columns + leads)
4. Test Tab cycling through page regions
5. Document: screenshot per shortcut, console output

### Phase 3: Screen Reader Testing (NVDA)
1. Start NVDA
2. Open app in Chrome/Firefox
3. Navigate with NVDA:
   - Virtual Cursor + Browse Mode (read all elements)
   - Focus Mode + keyboard (keyboard navigation)
4. Verify: All interactive elements announced
5. Log: Issues found, NVDA output

### Phase 4: Visual Validation (Contrast, Focus)
1. Lighthouse audit (DevTools)
2. WAVE browser extension scan
3. Focus outline visibility at normal + 200% zoom
4. Color contrast check (all text + UI)
5. Document findings
