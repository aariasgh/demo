## 📖 Historia de Usuario

**Como** usuario de CRM (ejecutivo de venta, manager, stakeholder)  
**Quiero** usar la aplicación cómodamente en cualquier dispositivo (mobile 320px, tablet 768px, desktop 1200px+)  
**Para que** pueda acceder al pipeline de leads desde mi teléfono, tablet o computadora sin comprometer usabilidad  

### Problema que Resuelve

- **Fragmentación de dispositivos:** Hoy los usuarios están atrapados en desktop; si usan mobile, todo es tiny/unreadable
- **Pérdida de contexto:** No poder verificar el estado de un lead mientras estoy de viaje = pérdida de productividad
- **Accesibilidad limitada:** Touch targets en mobile son muy pequeños (18x18px en lugar de 44x44px)
- **Layout shift:** Cuando cambio de orientación (portrait/landscape), el layout se quiebra
- **Legibilidad comprometida:** Fonts + spacing no se adaptan, causando fatiga visual

### Contexto de Negocio

- **Preparación para Demo:** Stakeholders van a probar en múltiples dispositivos el 8 de junio
- **Escalabilidad UX:** Producción necesita soporte mobile-first (ventas en campo = mobile)
- **WCAG AA Compliance:** Accesibilidad no es opcional, es estándar profesional
- **Confianza en escala:** Si el sistema no funciona en todos los dispositivos, se percibe como incompleto

### **2. Componente KanbanBoard — Responsive Layout**

**Ubicación:** `frontend/src/components/KanbanBoard.tsx` (MODIFICAR)

```typescript
import React from 'react';
import KanbanColumn from './KanbanColumn';
import { useLeadsStore } from '@/store/leadsStore';

/**
 * Responsive Kanban Layout:
 * - xs (320px): grid-cols-1 (stacked vertical)
 * - md (768px): grid-cols-2 (2 columns, scroll horizontal for rest)
 * - lg (1024px): grid-cols-3 (stretch, 4th column scrollable)
 * - xl (1280px): grid-cols-4 (all 4 visible, no horizontal scroll)
 */
export const KanbanBoard: React.FC = () => {
  const columns = useLeadsStore((s) => s.getColumnsWithCounts());

  return (
    <div className="kanban-container h-full w-full overflow-auto bg-gray-50 p-4 md:p-6">
      {/* Responsive Grid */}
      <div
        className={`
          grid
          gap-4 md:gap-6
          grid-cols-1 md:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4
          auto-cols-max
          w-full
          min-h-full
        `}
      >
        {columns.map((column) => (
          <KanbanColumn
            key={column.status}
            status={column.status}
            leads={column.leads}
            count={column.count}
            className={`
              min-w-full md:min-w-[calc(50%-12px)] lg:min-w-[calc(33.333%-16px)] xl:min-w-[calc(25%-18px)]
              flex-shrink-0
            `}
          />
        ))}
      </div>
    </div>
  );
};

export default KanbanBoard;
```

**Tailwind Classes Breakdown:**

| Clase | Uso |
|-------|-----|
| `grid-cols-1` | Mobile: 1 columna (stacked) |
| `md:grid-cols-2` | Tablet 768px+: 2 columnas |
| `lg:grid-cols-3` | Desktop 1024px+: 3 (preparación para 4ta) |
| `xl:grid-cols-4` | Desktop 1280px+: 4 columnas |
| `gap-4 md:gap-6` | Spacing: 16px mobile, 24px desktop |
| `p-4 md:p-6` | Container padding: 16px mobile, 24px desktop |
| `overflow-auto` | Scroll cuando contenido excede |

```typescript
import { render, screen } from '@testing-library/react';
import { describe, it, expect, beforeEach } from 'vitest';
import KanbanBoard from '../KanbanBoard';

describe('KanbanBoard - Responsive Layout', () => {
  // Helper: set viewport size
  const setViewport = (width: number, height: number) => {
    Object.defineProperty(window, 'innerWidth', {
      writable: true,
      configurable: true,
      value: width,
    });
    window.dispatchEvent(new Event('resize'));
  };

  describe('Mobile 320px', () => {
    beforeEach(() => setViewport(320, 568));

    it('AC-1: renders columns stacked vertically (1 column visible)', () => {
      render(<KanbanBoard />);
      const grid = screen.getByRole('region').querySelector('.grid');
      expect(grid).toHaveClass('grid-cols-1');
    });

    it('AC-2: no horizontal scroll', () => {
      render(<KanbanBoard />);
      const container = screen.getByRole('region');
      expect(container).toHaveClass('overflow-auto');
      // Verify no overflow-x: scroll in children
      expect(container.querySelector('.overflow-x-auto')).not.toBeInTheDocument();
    });

    it('AC-7: input height >= 44px', () => {
      render(<CreateLeadModal isOpen />);
      const input = screen.getByPlaceholderText('Juan García');
      expect(input.offsetHeight).toBeGreaterThanOrEqual(44);
    });

    it('AC-6: button height >= 48px', () => {
      render(<CreateLeadModal isOpen />);
      const btn = screen.getByRole('button', { name: /Crear Lead/i });
      expect(btn.offsetHeight).toBeGreaterThanOrEqual(48);
    });
  });

  describe('Tablet 768px', () => {
    beforeEach(() => setViewport(768, 1024));

    it('AC-3: renders 2 columns side-by-side', () => {
      render(<KanbanBoard />);
      const grid = screen.getByRole('region').querySelector('.grid');
      expect(grid).toHaveClass('md:grid-cols-2');
    });
  });

  describe('Desktop 1280px+', () => {
    beforeEach(() => setViewport(1280, 720));

    it('AC-4: renders 4 columns without horizontal scroll', () => {
      render(<KanbanBoard />);
      const grid = screen.getByRole('region').querySelector('.grid');
      expect(grid).toHaveClass('xl:grid-cols-4');
    });
  });

  describe('Typography Responsive', () => {
    it('AC-11 & AC-12: font-size matches breakpoint', () => {
      const { container } = render(<LeadCard lead={mockLead} />);
      const name = container.querySelector('h3');
      
      // Mobile: 14px (text-sm)
      setViewport(320, 568);
      expect(getComputedStyle(name).fontSize).toBe('14px');
      
      // Desktop: 16px (text-base)
      setViewport(1280, 720);
      expect(getComputedStyle(name).fontSize).toBe('16px');
    });

    it('AC-13: padding is responsive', () => {
      const { container } = render(<KanbanBoard />);
      const kanban = container.firstChild;
      
      // Mobile: p-4 = 16px
      setViewport(320, 568);
      expect(getComputedStyle(kanban).padding).toBe('16px');
      
      // Desktop: p-6 = 24px
      setViewport(1280, 720);
      expect(getComputedStyle(kanban).padding).toBe('24px');
    });
  });

  describe('No Layout Shift', () => {
    it('AC-5: smooth transition between breakpoints', async () => {
      const { container } = render(<KanbanBoard />);
      const initialPosition = container.getBoundingClientRect();

      setViewport(320, 568);
      await new Promise(resolve => setTimeout(resolve, 300)); // Debounce
      
      setViewport(768, 1024);
      await new Promise(resolve => setTimeout(resolve, 300));
      
      const finalPosition = container.getBoundingClientRect();
      
      // Position should be relatively stable (not jumping erratically)
      expect(Math.abs(initialPosition.top - finalPosition.top)).toBeLessThan(50);
    });
  });
});
```

## 📝 Notas de Implementación

1. **Tailwind Compilation:** Asegurarse de que Tailwind está compilando correctamente (check: `npm run build`)
2. **Media Query Order:** Las media queries deben estar en orden (xs → sm → md → lg → xl) para que cascade funcione
3. **Specificity:** Evitar conflictos de especificidad (base → responsive → hover/active)
4. **Touch Targets:** 44px es mínimo para toque, 48px es mejor (Apple/Google guidelines)
5. **Scroll Smoothing:** `-webkit-overflow-scrolling: touch` es crítico en iOS para UX suave
6. **No Layout Shift:** Usar `scrollbar-gutter: stable` para evitar shift cuando scroll aparece/desaparece
7. **Performance:** Testear en device real (no solo Chrome DevTools) — velocidad de zoom es distinta
8. **Orientation:** Probar landscape/portrait en mobile (requiere Media Queries adicionales si needed)
