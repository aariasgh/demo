## 🎯 STORY REQUIREMENTS

### User Story Statement

**Como** ejecutivo de venta,  
**quiero** ver un tablero Kanban con 4 columnas (Nuevo, En contacto, Propuesta, Cerrado),  
**para que** tenga una vista clara del pipeline comercial sin necesidad de dejar el dashboard.

### Business Value

- ✅ **Visual Pipeline:** Vista clara del estado de cada lead en tiempo real
- ✅ **Reduces Friction:** No necesita clicks innecesarios para ver el pipeline
- ✅ **Foundation for Drag & Drop:** E3-S3 (drag & drop) depende de esta renderización
- ✅ **Responsive:** Funciona en mobile (320px), tablet (768px), desktop (1200px+)
- ✅ **Performance:** Soporta 50+ leads sin lag perceptible

## 📂 FILE STRUCTURE & CODE PATTERNS

### KanbanBoard.tsx (Container Component)

```typescript
import { useQuery } from '@tanstack/react-query';
import { useMemo } from 'react';
import { useLeadsByStatus } from '../hooks/useLeads';  // From E3-S1
import KanbanColumn from './KanbanColumn';

interface LeadsByStatus {
  [key: string]: Lead[];
}

export default function KanbanBoard() {
  const { data: leads = [], isLoading, error } = useLeads();
  
  // Group leads by status
  const leadsByStatus = useMemo(() => {
    return {
      "Nuevo": leads.filter(l => l.status === "Nuevo"),
      "En contacto": leads.filter(l => l.status === "En contacto"),
      "Propuesta enviada": leads.filter(l => l.status === "Propuesta enviada"),
      "Cerrado": leads.filter(l => l.status === "Cerrado"),
    };
  }, [leads]);

  if (isLoading) return <div>Cargando pipeline...</div>;
  if (error) return <div>Error cargando leads</div>;

  return (
    <div className="p-6 bg-gray-50 min-h-screen">
      <h1 className="text-3xl font-bold mb-6">Pipeline de Ventas</h1>
      
      {/* Responsive Grid: 1 col (mobile) → 2 col (tablet) → 4 col (desktop) */}
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">
        {Object.entries(leadsByStatus).map(([status, statusLeads]) => (
          <KanbanColumn
            key={status}
            status={status}
            leads={statusLeads}
            count={statusLeads.length}
          />
        ))}
      </div>
    </div>
  );
}
```

**KEY POINTS:**
- `useMemo` for grouping (prevents re-grouping on every render)
- Responsive grid using Tailwind breakpoints
- Error/loading states
- Map over grouped leads to create columns

### KanbanColumn.tsx (Column Component)

```typescript
import LeadCard from './LeadCard';
import { STATUS_COLORS } from '../utils/constants';
import type { Lead } from '../types/lead';

interface KanbanColumnProps {
  status: string;
  leads: Lead[];
  count: number;
}

export default function KanbanColumn({ status, leads, count }: KanbanColumnProps) {
  const color = STATUS_COLORS[status] || '#6B7280';

  return (
    <div className="bg-white rounded-lg border border-gray-200 p-4 shadow-sm">
      {/* Column Header */}
      <div className="flex items-center justify-between mb-4 pb-4 border-b border-gray-200">
        <div className="flex items-center gap-2">
          {/* Status Icon (colored circle) */}
          <div
            className="w-4 h-4 rounded-full"
            style={{ backgroundColor: color }}
          />
          <h2 className="font-semibold text-gray-900">{status}</h2>
        </div>
        
        {/* Counter Badge */}
        <span className="inline-flex items-center px-2.5 py-0.5 rounded-full text-sm font-medium bg-gray-100 text-gray-800">
          {count}
        </span>
      </div>

      {/* Column Content — Scrollable */}
      <div className="space-y-3 max-h-[calc(100vh-200px)] overflow-y-auto">
        {leads.length > 0 ? (
          leads.map((lead) => (
            <LeadCard key={lead.id} lead={lead} />
          ))
        ) : (
          <div className="text-center py-8">
            <p className="text-gray-500 text-sm">No hay leads aún</p>
            <p className="text-gray-400 text-xs mt-1">Crea tu primer lead</p>
          </div>
        )}
      </div>
    </div>
  );
}
```

**KEY POINTS:**
- Header with icon (colored circle) and counter
- Empty state when no leads
- `overflow-y-auto` for vertical scroll within column
- `max-h-[calc(...)]` to prevent column overflow (responsive)
- Use CSS variables for colors (from constants)

### LeadCard.tsx (Card Component)

```typescript
import { useState } from 'react';
import type { Lead } from '../types/lead';

interface LeadCardProps {
  lead: Lead;
  onEdit?: (leadId: string) => void;
  onDelete?: (leadId: string) => void;
}

export default function LeadCard({ lead, onEdit, onDelete }: LeadCardProps) {
  const [isHovering, setIsHovering] = useState(false);

  return (
    <div
      className={`
        p-3 rounded-lg border-2 transition-all duration-150 cursor-grab
        ${isHovering 
          ? 'border-blue-500 shadow-md' 
          : 'border-gray-200 shadow-sm bg-white'}
      `}
      onMouseEnter={() => setIsHovering(true)}
      onMouseLeave={() => setIsHovering(false)}
      draggable={false}  // Will be enabled in E3-S3
    >
      {/* Lead Name (Bold) */}
      <p className="font-semibold text-gray-900 text-sm">{lead.name}</p>

      {/* Company (Gray) */}
      <p className="text-gray-600 text-xs mt-1">{lead.company}</p>

      {/* Email (Light Gray) */}
      <p className="text-gray-400 text-xs mt-0.5">{lead.email}</p>

      {/* Action Buttons (visible on hover) */}
      {isHovering && (
        <div className="flex gap-2 mt-3 pt-3 border-t border-gray-100">
          <button
            onClick={() => onEdit?.(lead.id)}
            className="flex-1 px-2 py-1 text-xs bg-blue-50 text-blue-600 rounded hover:bg-blue-100"
          >
            Editar
          </button>
          <button
            onClick={() => onDelete?.(lead.id)}
            className="flex-1 px-2 py-1 text-xs bg-red-50 text-red-600 rounded hover:bg-red-100"
          >
            Opciones
          </button>
        </div>
      )}
    </div>
  );
}
```

**KEY POINTS:**
- Hover state for border color + shadow
- Cursor: grab (CSS for drag hint)
- Action buttons only visible on hover
- Minimal height (will adjust in E3-S3 for drag feedback)
- No drag implementation yet (E3-S3 adds react-beautiful-dnd)
