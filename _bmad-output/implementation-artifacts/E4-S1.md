## 📋 STORY CONTEXT

### Objetivo
Implementar search box (nombre/empresa/email) + priority filter dropdown en header del Kanban, permitiendo filtrado en tiempo real con debounce.

### Problema que Resuelve
- Usuarios con 50+ leads no pueden encontrar leads rápidamente
- Ejecutivos de ventas pierden tiempo scrolleando todas las columnas
- AC-MVP-U3 requirement: "Búsqueda filtra en tiempo real"

### User Story
> **Como** Ejecutivo de Ventas  
> **Quiero** buscar leads por nombre/empresa/email  
> **Para que** pueda encontrar un lead específico en < 10 segundos

### State Management
```typescript
// Zustand store
interface KanbanFilterStore {
  searchQuery: string;
  selectedPriorities: LeadPriority[];
  setSearchQuery: (query: string) => void;
  setPriorities: (priorities: LeadPriority[]) => void;
  clearFilters: () => void;
}

// Computed state
const filteredLeads = useMemo(() => {
  return leads.filter(lead => {
    // Search: check name, company, email
    const matchesSearch = searchQuery === '' || 
      lead.name.toLowerCase().includes(searchQuery.toLowerCase()) ||
      lead.company.toLowerCase().includes(searchQuery.toLowerCase()) ||
      lead.email.toLowerCase().includes(searchQuery.toLowerCase());
    
    // Filter: check priority
    const matchesPriority = selectedPriorities.length === 0 ||
      selectedPriorities.includes(lead.priority);
    
    return matchesSearch && matchesPriority;
  });
}, [leads, searchQuery, selectedPriorities]);
```

### Debounce Implementation
```typescript
// 300ms debounce using useEffect
const [searchInput, setSearchInput] = useState('');
const [debouncedQuery, setDebouncedQuery] = useState('');

useEffect(() => {
  const timer = setTimeout(() => {
    setDebouncedQuery(searchInput);
  }, 300);
  
  return () => clearTimeout(timer);
}, [searchInput]);
```
