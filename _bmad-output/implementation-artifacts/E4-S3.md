## 📋 STORY CONTEXT

### Objetivo
Agregar status filter tabs en el header del Kanban, permitiendo al usuario ver solo 1-2 columnas de status (o todas).

### Problema que Resuelve
- Kanban con 50+ leads es abrumador (muchas columnas/mucho scroll)
- Usuario quiere enfocarse en un status específico
- Ejecutivo quiere ver solo "Propuesta" para revisar conversiones

### Decisión de Planning Review
> **Implementación:** Tabs en header: [Todos] [Nuevo] [En contacto] [Propuesta] [Cerrado]  
> **Independiente de E4-S1:** E4-S1 es search + priority filter. E4-S3 es status filter.  
> **Se combina con E4-S1:** Si user busca "juan" + filtra "Propuesta" → solo leads "juan" en Propuesta.

### User Story
> **Como** Ejecutivo de Ventas  
> **Quiero** filtrar el Kanban para ver solo un status  
> **Para que** pueda enfocarme en un stage específico del pipeline

### Component Implementation
```typescript
// components/StatusFilterTabs.tsx

export function StatusFilterTabs() {
  const { selectedStatus, setSelectedStatus } = useKanbanStore();
  
  const tabs = [
    { value: 'all', label: 'Todos' },
    { value: LeadStatus.NUEVO, label: 'Nuevo' },
    { value: LeadStatus.EN_CONTACTO, label: 'En contacto' },
    { value: LeadStatus.PROPUESTA, label: 'Propuesta' },
    { value: LeadStatus.CERRADO, label: 'Cerrado' }
  ];
  
  return (
    <div className="flex gap-2 pb-4 border-b border-gray-200 overflow-x-auto">
      {tabs.map(tab => (
        <button
          key={tab.value}
          onClick={() => setSelectedStatus(tab.value)}
          onKeyPress={(e) => e.key === 'Enter' && setSelectedStatus(tab.value)}
          className={`
            px-4 py-2 whitespace-nowrap font-medium rounded
            ${selectedStatus === tab.value 
              ? 'bg-blue-500 text-white border-b-2 border-blue-600' 
              : 'bg-gray-100 text-gray-700 hover:bg-gray-200'}
            transition-colors duration-200
          `}
          aria-pressed={selectedStatus === tab.value}
        >
          {tab.label}
        </button>
      ))}
    </div>
  );
}

// KanbanBoard.tsx - render columns conditionally
export function KanbanBoard() {
  const { visibleColumns, filteredLeads } = useKanbanStore();
  
  return (
    <div>
      <StatusFilterTabs />
      
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">
        {visibleColumns.map(status => (
          <KanbanColumn
            key={status}
            status={status}
            leads={filteredLeads.filter(l => l.status === status)}
          />
        ))}
      </div>
    </div>
  );
}
```
