## 🏗️ TECHNICAL REQUIREMENTS

### Architecture Decisions Applied

**Decision #1: Backend-driven validation**  
- ✅ Todas las validaciones ocurren en backend (single source of truth)
- ✅ Frontend puede hacer validaciones optimistas (pero no confiar en ellas)
- ✅ Backend siempre valida completamente antes de guardar

**Decision #2: Optimistic Updates Pattern**  
- ✅ Frontend actualizará state inmediatamente (sin esperar backend)
- ✅ Backend es fuente de verdad si hay conflictos
- ✅ Idempotency key required para retry safety (para E2-S1 es básico, será usado en E2-S3)

**Decision #3: Audit Trail**  
- ✅ Todo cambio se registra en `lead_audit_log`
- ✅ Permite reconstruir historial completo
- ✅ Base para future timeline/auditoría features

```python
"""Pydantic schemas for Lead API requests/responses"""

from pydantic import BaseModel, EmailStr, Field, field_validator
from datetime import datetime
from typing import Optional


class LeadBase(BaseModel):
    """Base schema with common Lead fields - DO NOT USE DIRECTLY"""
    name: str = Field(..., min_length=2, max_length=255, description="Lead name")
    company: str = Field(..., min_length=2, max_length=255, description="Company name")
    email: EmailStr = Field(..., description="Lead email (must be unique)")
    phone: Optional[str] = Field(None, max_length=20, description="Optional phone number")
    notes: Optional[str] = Field(None, max_length=1000, description="Optional notes")

    @field_validator('name', 'company', mode='before')
    @classmethod
    def strip_whitespace(cls, v):
        """Strip leading/trailing whitespace"""
        if isinstance(v, str):
            v = v.strip()
        return v

    @field_validator('name', 'company')
    @classmethod
    def not_empty_after_strip(cls, v):
        """Validate field is not empty after stripping"""
        if not v or not v.strip():
            raise ValueError('Field cannot be empty or contain only whitespace')
        return v

    @field_validator('notes')
    @classmethod
    def validate_notes_length(cls, v):
        """Validate notes don't exceed limit"""
        if v and len(v) > 1000:
            raise ValueError(f'notes cannot exceed 1000 characters (you provided {len(v)})')
        return v


class LeadCreate(LeadBase):
    """Schema for POST /api/leads request"""
    pass


class LeadResponse(LeadBase):
    """Schema for API response - includes DB-generated fields"""
    id: int
    status: str = Field(default="Nuevo", description="Lead status")
    created_at: datetime
    updated_at: datetime

    class Config:
        from_attributes = True  # Allow ORM model conversion
```

**Notes:**
- Use `EmailStr` from pydantic for email validation (installed as dependency)
- `field_validator` for custom validation logic
- `mode='before'` for preprocessing (strip whitespace)
- `from_attributes=True` allows direct conversion from ORM Lead model

### Phase 3: FastAPI Route Handler (NEW)

**File:** `backend/app/routers/leads.py`

```python
"""Lead CRUD endpoints"""

import logging
from fastapi import APIRouter, HTTPException, status
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.exc import IntegrityError
from sqlalchemy import select

from app.database import get_db
from app.models.lead import Lead
from app.models.audit import LeadAuditLog
from app.schemas.lead import LeadCreate, LeadResponse
from datetime import datetime
import json

logger = logging.getLogger(__name__)

router = APIRouter(prefix="/api/leads", tags=["leads"])


@router.post("", response_model=LeadResponse, status_code=status.HTTP_201_CREATED)
async def create_lead(
    lead_data: LeadCreate,
    db: AsyncSession = Depends(get_db),
) -> LeadResponse:
    """
    Create a new lead with complete validation and audit trail.
    
    - Validates all input fields (name, company, email, phone, notes)
    - Checks for email uniqueness
    - Creates lead and audit log in single transaction
    - Returns 201 Created with full lead details
    
    Raises:
        HTTPException 400: Validation error (handled by Pydantic)
        HTTPException 409: Email already exists
        HTTPException 500: Database error
    """
    
    try:
        # Check email uniqueness BEFORE creating lead
        # (SQLAlchemy unique constraint will also catch this, but we provide better error)
        stmt = select(Lead).where(Lead.email == lead_data.email)
        existing = await db.execute(stmt)
        if existing.scalars().first():
            logger.warning(f"Attempted duplicate email: {lead_data.email}")
            raise HTTPException(
                status_code=status.HTTP_409_CONFLICT,
                detail="Email ya existe en el sistema",
                headers={"X-Error-Code": "EMAIL_DUPLICATE"},
            )
        
        # Create new lead with timestamps
        new_lead = Lead(
            name=lead_data.name,
            company=lead_data.company,
            email=lead_data.email,
            phone=lead_data.phone,
            status="Nuevo",  # Always default status
            notes=lead_data.notes,
            created_at=datetime.utcnow(),
            updated_at=datetime.utcnow(),
        )
        
        db.add(new_lead)
        await db.flush()  # Get the ID without committing
        
        # Create audit log entry
        audit_log = LeadAuditLog(
            lead_id=new_lead.id,
            event_type="CREATED",
            old_value=None,
            new_value={
                "name": new_lead.name,
                "company": new_lead.company,
                "email": new_lead.email,
                "phone": new_lead.phone,
                "status": new_lead.status,
                "notes": new_lead.notes,
            },
            description=f"Lead created with email {new_lead.email}",
            created_by_id=None,  # Future: from auth context
            created_at=datetime.utcnow(),
            metadata={"ip_address": None},  # Future: from request
        )
        
        db.add(audit_log)
        
        # Commit transaction (both lead and audit log)
        await db.commit()
        
        logger.info(
            f"Lead created successfully",
            extra={
                "lead_id": new_lead.id,
                "email": new_lead.email,
                "name": new_lead.name,
            },
        )
        
        # Refresh to ensure all fields are populated
        await db.refresh(new_lead)
        return new_lead
        
    except IntegrityError as e:
        await db.rollback()
        logger.error(f"Database integrity error: {str(e)}", exc_info=True)
        raise HTTPException(
            status_code=status.HTTP_409_CONFLICT,
            detail="Email ya existe en el sistema",
        )
    except Exception as e:
        await db.rollback()
        logger.error(f"Unexpected error creating lead: {str(e)}", exc_info=True)
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail="Error al crear el lead",
        )
```

**Implementation Notes:**
- Check email uniqueness BEFORE db.add() for clearer error handling
- Use `await db.flush()` to get ID without committing yet
- Create audit log in same transaction (ACID guarantee)
- Always catch `IntegrityError` as fallback (shouldn't happen if pre-check works, but defensive)
- Log with structured context (lead_id, email, name) for debugging
- Use `from_attributes=True` in schema for ORM → Pydantic conversion

```python
"""Database connection and session management"""

from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
from sqlalchemy.orm import sessionmaker
from app.config import settings
import logging

logger = logging.getLogger(__name__)

# Create async engine with connection pooling
engine = create_async_engine(
    settings.DATABASE_URL,
    echo=False,  # Set to True for SQL debug logging
    pool_size=5,
    max_overflow=20,
    pool_pre_ping=True,  # Test connections before using
)

# Create async session factory
async_session = sessionmaker(
    engine,
    class_=AsyncSession,
    expire_on_commit=False,
)


async def get_db() -> AsyncSession:
    """Dependency injection for FastAPI endpoints"""
    async with async_session() as session:
        try:
            yield session
        finally:
            await session.close()
```

## 🛡️ DEVELOPER GUARDRAILS (CRITICAL - READ CAREFULLY)

### Gotchas & Common Mistakes to Avoid

**❌ MISTAKE 1: Forgetting transactions**  
```python
# WRONG - audit log created even if lead creation fails
new_lead = Lead(...)
db.add(new_lead)
audit = LeadAuditLog(...)
db.add(audit)
await db.commit()
```

**✅ CORRECT - Use flush() before creating audit log**
```python
# RIGHT - both success or both rollback
new_lead = Lead(...)
db.add(new_lead)
await db.flush()  # Get ID, but don't commit
lead_id = new_lead.id
audit = LeadAuditLog(lead_id=lead_id, ...)
db.add(audit)
await db.commit()
```

**❌ MISTAKE 2: Not handling IntegrityError**  
```python
# WRONG - email duplicate returns 500, not 409
try:
    await db.commit()
except Exception:
    raise HTTPException(500)
```

**✅ CORRECT - Specific error handling**
```python
try:
    # Pre-check email
    existing = await db.execute(select(Lead).where(...))
    if existing.scalars().first():
        raise HTTPException(409, "Email ya existe")
    
    # Create and commit
    await db.commit()
except IntegrityError:  # Fallback catch
    await db.rollback()
    raise HTTPException(409, "Email ya existe")
```

**❌ MISTAKE 3: Forgetting async/await**  
```python
# WRONG - blocking call in async function
db.execute(stmt)  # No await!
```

**✅ CORRECT - All DB calls must be awaited**
```python
result = await db.execute(stmt)
existing = result.scalars().first()
```

**❌ MISTAKE 4: Not handling schema conversion**  
```python
# WRONG - LeadResponse expects Lead ORM model, but you return dict
return {"id": 1, "name": "Juan"}
```

**✅ CORRECT - Return ORM model, Pydantic converts**
```python
await db.refresh(new_lead)  # Ensure all fields populated
return new_lead  # FastAPI + LeadResponse schema handles conversion
```
